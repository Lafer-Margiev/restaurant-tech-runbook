# 📖 Restaurant Tech Runbook
**Objective:** A collection of technical SOPs and troubleshooting protocols designed to maintain 100% system uptime in Michelin-star, high-volume environments.

### 🛠️ Systems Covered
- **POS:** Toast & Aloha (Hardware/Software)
- **Networking:** Local Failover & Offline Mode Protocols
- **Integration:** SevenRooms/Resy API troubleshooting

### 📋 Sample Guides included:
1. **Network Failover:** Steps to transition Toast POS to "Offline Mode" during ISP outages.
2. **KDS Troubleshooting:** Resetting Kitchen Display Systems without losing active ticket data.
3. **Hardware Audit:** Weekly diagnostic checklist for thermal printers and handheld tablets.

*Note: These guides are generalized for portfolio purposes and do not contain proprietary data from previous employers.*
